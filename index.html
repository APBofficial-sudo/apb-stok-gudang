Kertas stiker

Koreksi dari hasil cetak (lihat 4 label pojok)

Cetak lembar uji dengan skala 100 % di kertas stiker (atau di kertas biasa, tumpuk di atas stiker lalu terawang). Ukur dulu garis 150 mm-nya: kalau lebih pendek, masalahnya skala cetak, bukan tata letak. Lalu lihat label di 4 pojok: isi berapa mm cetakan meleset dari stikernya; yang sudah pas biarkan 0.

Atau: ukur kertas stiker dengan penggaris

Ukur di kertas stiker aslinya, dalam mm, dari tepi kertas ke tepi label. Lebar/tinggi label diambil dari kolom di atas.

Isi label

Isi jumlah stiker untuk melihat ukuran barcode.
Pengaturan saat tombol Cetak diklik
  1. Kertas A4, tegak (portrait).
  2. Skala 100 % / Actual size — bukan "Fit", "Fit to printable area", atau "Shrink". Ini penyebab paling sering label meleset: tengah pas, pinggir lari.
  3. Margin: Tidak ada / None.
  4. Matikan header & footer.
  5. Pertama kali: cetak lembar uji, bandingkan dengan stiker. Kalau meleset, isi Koreksi dari hasil cetak di atas.
  6. Tombol Unduh PDF menyimpan file yang sama untuk dicetak nanti atau di tempat lain — tetap cetak dengan skala 100%.

Sambungan ke server

Alamat web app dari Apps Script (berakhiran /exec), PIN dari tab PENGATURAN di spreadsheet, dan nama petugas yang memakai perangkat ini.

Tautan untuk HP / perangkat lain

Kirim tautan ini ke WhatsApp staf. Dibuka di HP, aplikasi terbuka dengan alamat server sudah terisi — tinggal isi PIN dan nama. Kamera langsung jalan di alamat ini.
